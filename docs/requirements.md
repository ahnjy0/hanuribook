# 한우리독서토론논술 홈페이지 리뉴얼 — 개발 내용 정리

배포 사이트: https://ahnjy0.github.io/hanuribook
저장소: `ahnjy0/hanuribook` (`main` 브랜치 push 시 자동 배포)

이 문서는 배포 사이트를 만드는 소스 코드(`src/`)를 기준으로, 지금까지 구현된 기능과 남은 작업을 정리했습니다. 디자인 규칙(색 · 간격 · 컴포넌트 모양)은 [design.md](design.md)에 있습니다.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 목적 | 한우리독서토론논술(독서 · 토론 · 논술 교육 브랜드) 홈페이지의 반응형 리뉴얼 |
| 이전 형태 | 하나의 정적 `index.html` 프로토타입(저장소 루트, 참고용 · 배포 안 함) |
| 현재 형태 | Next.js App Router 기반 정적 사이트 |
| 대상 사용자 | 학부모(프로그램 탐색 · 상담 신청 · 센터 찾기), 예비 교사 · 센터 운영 희망자(교사 모집 · 설명회 · 센터 개설 문의) |
| 지원 화면 | 모바일 · 태블릿 · 데스크톱(모바일 우선, `md` 768px · `lg` 1024px) |

## 2. 기술 구성

| 구분 | 내용 |
|---|---|
| 프레임워크 | Next.js 16(App Router) + React + TypeScript |
| 스타일 | Tailwind CSS v4(Preflight 없음, 임의값 유틸리티), Pretendard 글꼴 |
| 빌드 · 배포 | `output: "export"` 정적 빌드 → `out/` → GitHub Actions(`.github/workflows/deploy.yml`) → GitHub Pages |
| 하위 경로 | Pages가 `/<저장소이름>/`에서 열려 `PAGES_BASE_PATH`로 `basePath`/`assetPrefix` 지정. 내부 링크는 `next/link`(또는 `SmartLink`), 로컬 이미지는 `import`로 불러와야 함 |
| 검사 | `npm run typecheck`(`tsc --noEmit`)만 있음 — 린터 · 테스트 없음 |
| 외부 연동 | 카카오(다음) 우편번호 서비스(주소 검색, API 키 불필요) |
| 이미지 | `cdn.hanuribook.com` 등 외부 CDN의 일반 `<img>`(`next/image` 최적화 미사용) |

### 정적 사이트 제약

서버 기능(Route Handler, Server Action, 쿠키 · 헤더 읽기, 런타임 렌더링, 이미지 최적화)을 쓸 수 없습니다. 그래서 **모든 신청 · 문의 폼은 화면 흐름만 동작하고 실제 전송은 하지 않습니다**(7장 참고).

## 3. 코드 구조

| 위치 | 역할 |
|---|---|
| `src/app/<route>/page.tsx` | 얇은 래퍼 — `metadata`(제목 끝에 `SITE_TITLE`) + view 렌더링 |
| `src/routes.ts` | 모든 라우트 경로(`PATHS`). 내부 링크는 이 값을 사용 |
| `src/views/<Page>/` | 페이지별 화면. `<Page>.tsx`가 Header → `sections/*` → Footer(→ BottomNav) 순으로 조립, 상태 · 데이터는 `use<Page>.ts` |
| `src/components/templates/` | 여러 라우트가 함께 쓰는 데이터 기반 템플릿: `CourseHub`, `ProgramDetail`, `SpecialDetail` |
| `src/components/common/` | Header · Footer · BottomNav · SectionLabel · SmartLink · ProgramFaqSection 등 |
| `src/components/common/AppShell` | 루트 레이아웃. `href="#"`는 동작 없음, `href="#id"`는 부드러운 스크롤 |
| `src/styles/globals.css` | 테마 값, 애니메이션, `reveal` 유틸리티, 데스크톱 글자 확대 규칙 |

## 4. 페이지별 기능

### 4-1. 메인 (`/`)
- 히어로, 수업 방식, 연혁, 서비스 섹션, 스크롤 등장 모션
- **한우리 프로그램**: 정규 · 정규 심화 · 특강 탭 전환 카드. 카드 색은 각 프로그램 페이지 색과 연결
  - 정규: 연령 박스 + 과정명 + 한 줄 설명
  - 정규 심화: 과정 아이콘 박스 + 학년 + 과정명
  - 특강: 분야 박스(특강 색을 연하게) + 학년 + 과정명
- 하단 고정 바: 센터찾기 · 무료 수업 & 상담 신청하기

### 4-2. 프로그램
| 페이지 | 기능 |
|---|---|
| 소개 (`/program`) | 프로그램 특징, 수업 방식 · 선생님 · 장소 · 시작 · 성과 섹션. **프로그램 전체 보기** 모달(연령 × 정규 / 정규 심화 / 단기 특강 커리큘럼 표, 프로그램별 색) |
| 유아정규 (`/kinder`) | 분홍 테마, 단계 · 교재 구성 · 학습 효과 · FAQ |
| 초등정규 · 초등심화 · 중고등정규 | `CourseHub` 과정 목록 → 과정 상세(`detail-*`, `ProgramDetail`) |
| 단기특강 목록 (`/special`) | 특강 카드 3열(분야 · 대상 알약, "프로그램명 상세보기" 버튼) |
| 단기특강 상세 (`special-*`) | `SpecialDetail` 템플릿: 참깨한글 · 다다어휘 · 똑독해 · 문학 특강(별별 문학 독해 + 교과 문학 탐독) · 소클 고등 통합사회. 히어로 이미지 패턴, 고민 말풍선 슬라이드, 주요 특징, 교재 구성, 수업 내용, 학습 효과 등 블록을 데이터로 조립 |

### 4-3. 수업상담 (`/consult`)
- 자녀 학년 선택(13개, 중복 선택) · 보호자 정보(성함, 휴대폰 번호 + 인증, 주소 검색, 상담 희망 시간)
- 휴대폰 인증: 번호 형식 검사 → 3분 타이머 → 6자리 입력 후 확인(**화면 흐름만**, SMS 미연동)
- 개인정보 수집 · 이용 / 제3자 제공 동의(필수) + 자세히보기 모달(안 할래요 · 동의해요)
- 신청 완료 카드(접수는 전송되지 않음)

### 4-4. 센터찾기 (`/centers`)
- 검색창 · 시/도 · 구/군 선택(목업 데이터)
- 지도(임시 그림, `[지도 API 영역]`) + 센터 카드 목록(유형 아이콘, 주소 · 운영 시간, 전화 문의 · 상담 예약하기)
- 위치보기: 모바일은 아래에서 올라오는 지도 시트, 데스크톱은 가운데 모달(지부 정보 · 주소 · 강조된 마커)
- 하단 고정 바 없음

### 4-5. 한우리선생님
| 페이지 | 기능 |
|---|---|
| 한우리선생님 (`/teacher`) | 히어로(글 + 사진), 한우리 선생님의 특징(4가지), 전문 분야(독서지도사 · 토론논술교사), 학부모 후기(8개, 흐르는 카드), 수업상담 배너 |
| 교사특별반 (`/teacher-special`) | 히어로, 한우리에서 시작해야 하는 이유(7가지 — 브랜드 · 프리랜서 · 0원 · 광고/홍보 · 연령별 프로그램 · 활동 혜택 · 교육 시스템), 되는 방법(STEP), 신청 배너, 상담 신청서(성명 · 휴대전화 · 주소 · 동의 2개), FAQ |
| 지도교사 입문과정 (`/teacher-course`) | 히어로, 과정 안내(수강 형태 · 교육비 · 지원 자격 · 교육 내용), 진행 절차, 교육 일정 표(1~12월), 입문과정 신청 버튼(교육 사이트 새 창), FAQ |
| 온라인설명회 (`/seminar`) | 설명회 안내(일시 · 신청기간 · 장소 · 대상, 진행 순서, 참가자 혜택, 이벤트 유의사항) + 신청서(성명 · 휴대전화 · 궁금한 점 복수 선택 · 기타 150자 · 동의) |
| 센터모집 (`/franchise`) | 개설 절차(6단계), 개설 비용(지부 · 독서문화원 · 독서교실 3유형 표 + 안내사항), 교육 과정 안내 표, 개설 문의(권역별 전화, 수업 형태 · 이름 · 성별 · 연령 · 연락처 · 희망 지역 · 자격증 유무 · 상담 내용 · 희망 상담일 · 동의 + 자세히보기) |

- 한우리선생님 메뉴 5개 페이지는 하단 고정 바 없음

### 4-6. 공통
- **헤더**: 주 메뉴 4탭 · 2뎁스 · 3뎁스 메뉴, 현재 위치 강조
- **전체 메뉴**: 모바일 오른쪽 서랍 / 데스크톱 4열 패널(3뎁스 포함), 바깥 클릭 · Esc 닫기, 스크롤 잠금, 센터찾기 · 수업상담 바로가기
- **푸터**: 회사 정보 · 고객센터(02-6276-2666) · ISMS 배지
- **미리보기 라우트**(실제 페이지 아님): `/header`, `/footer`, `/bottom-nav`, `/style-guide`, `/desktop`, `/tablet-centers`, `/course-hub`, `/program-detail`

## 5. 폼 공통 규칙

| 규칙 | 내용 |
|---|---|
| 필수 검사 | 보내기 버튼을 누르면 위에서부터 첫 빈 항목을 안내 문구로 알림 |

| 전송 | **아직 없음** — 서버 · API 연동 필요 |

## 6. 접근성 · 품질 기준

- 의미 있는 이미지는 `alt`, 장식 이미지는 `alt=""` + `aria-hidden`
- 모달은 기본 `<dialog>`(Esc 닫기 · 포커스 가두기) 또는 `role="dialog"` + `aria-modal`, 닫기 버튼에 `aria-label`
- 탭 · 라디오 · 토글은 `aria-selected` · `aria-pressed` · `aria-current` 사용
- 모든 움직임은 `prefers-reduced-motion`(동작 줄이기)에서 정지 · 생략
- 화면 문구 · 코드 주석은 한국어

## 8. 작업 · 배포 절차

1. `npm run dev`로 로컬 확인(한 폴더에서 개발 서버는 하나만 실행)
2. `npm run typecheck` 통과 확인
3. `main`에 커밋 · 푸시(`next-env.d.ts`는 커밋하지 않음) → GitHub Actions가 빌드 후 Pages에 배포
4. 저장소 Settings → Pages → Source가 "GitHub Actions"여야 함
