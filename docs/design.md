# 한우리독서토론논술 사이트 디자인 정리

배포 사이트: https://ahnjy0.github.io/hanuribook (이 저장소 `main` 브랜치를 GitHub Pages로 정적 배포)

이 문서는 배포 사이트를 만드는 소스 코드(`src/`)를 기준으로 정리했습니다. 값은 코드에 실제로 쓰인 Tailwind 임의값입니다.

---

## 1. 전체 원칙

| 항목 | 내용 |
|---|---|
| 글꼴 | Pretendard(가변, `src/assets/fonts`) · 자간 `-0.02em`(일부 `-0.03em`) |
| 기본 글자색 | `#1F1F1F` (본문 보조 `#333333`, 설명 `#444444`·`#555555`, 흐린 안내 `#666666`·`#777777`·`#8A8A8A`) |
| 반응형 | 모바일 우선. `md`(768px) = 태블릿, `lg`(1024px) = 데스크톱 |
| 본문 폭 | `max-w-[1200px]` + 좌우 여백 `px-5`(20px) |
| 스타일 방식 | JSX 안 Tailwind 임의값(`text-[15px]`, `bg-[#F26522]`)만 사용, 토큰 클래스(`text-sm`) 쓰지 않음 |
| 리셋 | Tailwind Preflight 없음 → 요소마다 `m-0`, `border-0`, `list-none` 직접 지정 |
| 데스크톱 글자 확대 | `<main>` 안 `text-[13~16px]`은 데스크톱에서 자동으로 커짐(`globals.css`). 이미 `lg:text-[..]`가 있으면 제외 |
| 2단 배치 | 본문을 가로 두 칸으로 나눌 때는 데스크톱 **1:1**(`lg:grid-cols-2`)로 통일 |
| 이미지 | `<img>`로 `cdn.hanuribook.com`에서 불러옴(`width`·`height`·`loading="lazy"`), 장식은 `alt=""` + `aria-hidden` |


## 3. 주요 컴포넌트

### 공통 (`src/components/common`)

| 컴포넌트 | 역할 · 모양 |
|---|---|
| `Header` | 로고 + 전체 메뉴(☰). 주 메뉴 4탭(현재 탭 주황 글자 + 주황 밑줄), 2뎁스는 둥근 박스 버튼(현재 = 주황 채움), 3뎁스는 박스 없는 글자 메뉴(현재 = 점 + 진한 글자). `theme="pink"`로 강조색 분홍 전환 |
| 전체 메뉴(Header 안) | 모바일 오른쪽 서랍 / 데스크톱 위에서 내려오는 4열 패널. 배경 클릭 · Esc 닫기, 스크롤 잠금, 하단 센터찾기 · 수업상담 바로가기 |
| `Footer` | 진한 회색 바탕, 회사 정보 · 고객센터 · ISMS 배지 |
| `BottomNav` | 하단 고정 바: 센터찾기(연한 버튼) + 주 CTA(주황 채움). 한우리선생님 메뉴 · 센터찾기 페이지에는 없음 |
| `SectionLabel` | 둥근 알약 라벨(섹션 항목명). 기본 모바일 13px · 데스크톱 16px |
| `SmartLink` | 내부 경로(`/…`)는 `next/link`, `#id`는 `<a>`(페이지 안 부드러운 스크롤) |
| `ProgramFaqSection` | 회색 띠 + "FAQ" 라벨 + 접이식 질문(`<details>`). 질문 앞 `Q.`, 답변 앞 `A.` |
| `CenterKindIcon` | 센터 유형 아이콘(지부 = 깃발 건물, 독서교실 = 건물 + 책) |

### 섹션 제목 두 가지

| 방식 | 모양 | 사용처 |
|---|---|---|
| 가운데 라벨형 | `SectionLabel` 알약 + 가운데 큰 제목 | 과정 상세, 단기특강(참깨한글 · 다다어휘 · 똑독해), 프로그램 소개 히어로 |
| 왼쪽 타일 아이콘형 | 주황 사각 타일 아이콘(`TitleIcon`, 36→44px) + 왼쪽 정렬 제목(22→30px) | 프로그램 소개 본문, 한우리선생님 메뉴, 수업상담 계열, 문학 특강 · 통합사회 |

### 자주 쓰는 패턴

| 패턴 | 모양 |
|---|---|
| 히어로(살구색) | `bg-[#FFEDE0]` + 아래 모서리 `rounded-b-[32px]`, 데스크톱은 글(왼쪽) · 사진(오른쪽) 1:1 |
| 단기특강 히어로 | 특강 연한 색 바탕 + 이미지 패턴(45° 회전, 불투명도 5%) |
| 정보 카드 | 연한 살구색 `#FFF7F1` + 테두리 `#FBE7DA` + `rounded-[18px]` |
| 흰 카드(폼 · 안내) | 흰 바탕 + 테두리 `#EEEEEE` + `rounded-[24px]` |
| 이유 · 특징 줄 카드 | 흰 카드 안 1:1 — 왼쪽 큰 번호(주황) · 제목 · 설명 / 오른쪽 연한 살구색 그림 판 |
| 번호 단계 카드 | 번호 동그라미 + 단계명, 데스크톱은 카드 사이 `›` 화살표, 마지막 단계만 주황 강조(선택) |
| 알약 목록 | 흰 알약(`rounded-full`)에 짧은 항목 나열(혜택 · 수업 기준 등) |
| 신청 배너 | 주황 그라데이션 카드 + 흰 글자 + 흰 둥근 버튼, 옅은 흰 동그라미 장식 |
| 폼 | 묶음마다 흰 카드(`• 제목 (필수)` 머리), 회색 입력칸(`#F7F7F8`), 회색 동의 상자 + 자세히보기 모달, 파란 안내 상자(`#EAF2FF`), 꽉 찬 주황 버튼 |
| 모달 | 기본 `<dialog>`(Esc · 포커스 가두기), 바깥 클릭 닫기, 스크롤 잠금. 센터 위치보기는 모바일 아래에서 올라오는 시트 |
| 흐르는 카드 | 학부모 후기 — 카드 줄이 왼쪽으로 끝없이 흐름(45초), 마우스 올리면 멈춤 |

## 5. 간격 · 크기

### 5-1. 섹션 간격

| 위치 | 모바일 → 데스크톱 |
|---|---|
| 섹션 사이 위 여백 | `pt-12` 48px → `lg:pt-24` 96px |
| 히어로 바로 다음 첫 섹션 | `pt-8` 32px → `lg:pt-14` 56px |
| 제목과 내용 사이 | `gap-3.5` 14px → `lg:gap-5` 20px |
| 페이지 끝 여백 | `pb-16` 64px → `lg:pb-24` 96px |
| 히어로 안쪽 | `pt-9 pb-10` → `lg:pt-14 lg:pb-16` (프로그램 소개는 `lg:pt-16 lg:pb-20`) |
| 카드 사이 | `gap-3` 12px → `lg:gap-4` 16px |
| 카드 안쪽 | `p-5` 20px → `lg:p-6`~`lg:p-8` 24~32px |

### 5-2. 둥근 모서리

| 대상 | 값 |
|---|---|
| 히어로 아래 모서리 · 큰 배너 | 24~32px |
| 카드 | 18~24px |
| 입력칸 · 작은 버튼 | 12px |
| 큰 버튼 | 14px 또는 알약(`rounded-full`) |
| 알약 라벨 · 태그 | `rounded-full` |

### 5-3. 글자 크기(모바일 → 데스크톱)

| 대상 | 크기 |
|---|---|
| 페이지 제목(h1) | 26~28px → 36~40px |
| 섹션 제목(h2) | 22px → 30px |
| 카드 제목 | 16~19px → 18~26px |
| 본문 · 설명 | 14~15px → 16~17px |
| 보조 · 안내 | 12~13px → 13~14px |
| 버튼 | 15~17px |

### 5-4. 컨트롤 높이

입력칸 · 보조 버튼 52px(`h-13`), 큰 버튼 52~56px(`h-13`~`h-14`), 하단 고정 바 버튼 56px, 2뎁스 메뉴 40px 이상.
